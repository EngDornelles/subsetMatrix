# subsetmatrix_rs

Native Rust/PyO3 extension backing [`subsetmatrix`](https://pypi.org/project/subsetmatrix/)'s
fast numeric subset path (`subsetmatrix.native_backend.get_subsets_native`).

Not meant to be used standalone -- install `subsetmatrix`, which depends on
this package automatically.

See the [subsetMatrix repository](https://github.com/EngDornelles/subsetMatrix)
for documentation, source, and history.
